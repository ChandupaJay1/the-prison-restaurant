# The Prison Restaurant & Lounge Website

Modern, interactive 3D-enhanced restaurant website for **The Prison Restaurant & Lounge** (Piliyandala & Maharagama, Sri Lanka) — *Eat • Drink • Escape* (*මාංචු වෙනුවට කෑම*).

Developed by **[NerdTech Labs](http://nerdtechlabs.info/)**.

## Tech Stack
- **React 18** + **Vite**
- **Three.js** (WebGL 3D Dish Showcase, Atmospheric Embers, Interactive 3D Canvas)
- **Tailwind CSS**
- **Framer Motion** (Smooth animations & page transitions)
- **React Router DOM**
- **React Hook Form**
- **Lucide React Icons**

## Key Features
- **Cinematic Hero Section** with animated thunder & lightning storm atmosphere and full `EAT _ DRINK _ ESCAPE` watermark.
- **Interactive 3D WebGL Dish Showcase** with 360° rotatable holographic dish display, MagLev halo base, portion selector, and instant WhatsApp ordering.
- **3D Perspective Tilt Cards** with real-time specular glare across signature dishes and branches.
- **Kinetic Typography Marquee** & **Magnetic 3D Cursor**.
- **Complete Multi-Page Experience**: Home, About Us, Menu (with verified pricing & category filters), Photo Gallery (with Lightbox), Table Reservations (with instant WhatsApp booking), and Contact & Locations (with Google Maps embeds).

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
